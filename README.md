# pi-git-research

A [pi](https://github.com/badlogic/pi-mono) package for researching git repositories.

## Installation

```bash
pi install git:github.com/mjakl/pi-git-research
```

## Tools

- `git_repo`: Clone or update a git repository.
- `git_repo_summary`: Get a quick overview of a cloned repository.
- `git_repo_versions`: List branches and tags available in a repository.

## Skills

- `explore-repo`: Download, summarize, and orient in a git repository.
